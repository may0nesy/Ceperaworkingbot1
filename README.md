# 🤖 CeperaWorkingBot

Телеграм-бот для команды кальянной. Умеет проверять расписание сотрудника через Google Calendar, хранить рецепты миксов в PostgreSQL и помогать стаффу подбирать табак по координатам с полки.

---

## ✨ Функции

### 📅 Расписание Серёжи
Бот проверяет Google Calendar и отвечает, есть ли смена сегодня или завтра.

- Кнопка **«Работает ли Серёжа сегодня?»**
- Кнопка **«А завтра?»**
- Команды `/serezha` и `/serezha_zavtra`
- Упоминание `@bot_username` в любом чате — бот ответит автоматически

---

### 🎧 Миксы

**Записать микс** — FSM-цепочка из двух шагов:
1. Бот просит ввести название
2. Бот просит ввести состав
3. Микс сохраняется в PostgreSQL

На каждом шаге доступна кнопка **«Отмена»**:
- На этапе названия → возврат на главный экран
- На этапе состава → возврат к вводу названия

**Мои миксы** — просмотр сохранённых миксов с пагинацией:
- До 6 миксов на странице
- Навигация кнопками `‹` и `›`
- Нажатие на микс → карточка с названием и составом
- Кнопка **🗑 Удалить** с подтверждением

---

### 🎰 Стафф кальян *(закрытая функция)*

Доступна только пользователям из списка `STAFF_ALLOWED_IDS`. Кнопка не отображается у остальных.

Помогает случайным образом выбрать табак по координатам на полке (Полка X, Ряд Y).

**Фаза А — Основной табак:**

| Кнопка | Действие |
|---|---|
| Крутим 🎰 | Перегенерировать координаты |
| Похуй некст | Зафиксировать, перейти к додепу |
| Enough ✅ | Завершить (появляется после ≥1 полного сета) |

**Фаза Б — Додеп на контейнер:**

| Кнопка | Действие |
|---|---|
| Крутим 🎰 | Перегенерировать координаты додепа |
| Дальше ➡️ | Сохранить полный сет, вернуться к фазе А |

**Итог:**
```
Табак 1: 3 2 (Додеп: 1 4)
Табак 2: 5 1 (Додеп: 2 3)
```

---

### 📢 Рассылка *(только для админа)*

```
/broadcast <текст>
```
Отправляет сообщение всем пользователям из базы данных.

## 🗄️ База данных

Бот автоматически создаёт таблицы при первом запуске.

```sql
CREATE TABLE users (
    id         BIGINT PRIMARY KEY,
    username   TEXT,
    first_name TEXT,
    last_name  TEXT,
    date_added TIMESTAMPTZ DEFAULT NOW()
);

CREATE TABLE mixes (
    id          SERIAL PRIMARY KEY,
    user_id     BIGINT NOT NULL REFERENCES users(id),
    name        TEXT   NOT NULL,
    ingredients TEXT   NOT NULL,
    created_at  TIMESTAMPTZ DEFAULT NOW()
);
```

Пользователи регистрируются автоматически при любом обращении к боту (upsert — дублей нет).
